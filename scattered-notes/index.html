Scattered Notes

Notes get scattered. A to-do sits in one note, “call the bank tomorrow” sits in another, and a plan for next week is in a third.

Nothing connects them, so the only way to know what needs doing is to reread everything.

Scattered Notes is an app for Mac and Windows, with iPhone and Android companions, built around two steps:

Scroll ↓

1. Capture.

Get the thought down in seconds, without deciding where it goes.

▣ Inbox ▾
Type a quick note, thought, or checklist…
Esc Done+project File#tag Tag
Saves as you type

⌥ N on a Mac or Ctrl Alt N on Windows opens Quick Note over whatever you're doing. It saves as you type; press Esc when you're done. On a Mac it's ⌥ N from any app; on a phone, the Capture button. It saves as you type.

2. Unify.

A dashboard collects everything that needs action from all your notes, with nothing to set up.

01

It reads dates.

Write “call the bank tomorrow” and it shows up under Tomorrow. “Tomorrow” stays the day after you wrote it, however much the note changes later. Weekdays, “next week” and “oct 30” work too.

02

Tick things off.

Tick a to-do on the dashboard and it's ticked in the note. When everything for today is done, the count turns into a sun.

03

+project, #tag, @person.

Type +website to file a note in a project, #idea to tag it and @ana to mention someone. Each one gets its own list.

04

Every project has a dashboard.

Open a project to see its to-dos, then all its notes one after another, newest first, like a logbook.

05

Find anything.

⌘ K searches every note, and ⌥ F does it from any app. Pick a result and the cursor lands on the match.

06

Plain files, on every device.

Notes are Markdown files in a folder you own. Keep it in iCloud Drive or any synced folder, and the Mac, Windows, iPhone and Android apps all work from it.
