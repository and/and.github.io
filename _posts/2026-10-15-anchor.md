I start more things than I finish. A new idea always looks better than the one I'm halfway
through, and by evening I've spent the day on three things that weren't the plan.

**Anchor** is the app I built to stop that. It keeps me connected to a few goals I picked,
shows where my time actually went, and tells me, without cheering me on, when I'm drifting.

* Contents
{:toc}

## One number: alignment

Anchor's core is a single number: **alignment**, the share of today's screen time that went to
your goals. It's worked out from what you actually did, not what you meant to do.

- Websites, apps and window titles you list under a goal count toward it. A terminal tab
  named "DSA" counts toward DSA.
- Time inside a goal's timer counts toward that goal.
- Sites you mark as drift count as drift.
- Everything else is "Other".

You see today's alignment, the last 7 days, the last 8 weeks and the last 6 months, so you can
tell a bad afternoon from a bad month.

## Where you can't miss it

A dashboard you have to open is a dashboard you stop opening. So Anchor puts the answer where
you'll see it anyway:

- **The wallpaper and lock screen** on the Mac. Four short cards answer four questions:
  *How's today going? Am I improving? Am I on plan this week? When will I be done?*
  The wallpaper follows Light and Dark mode, and the text passes WCAG AA contrast.
- **The menu bar**, with today's alignment next to the anchor icon.
- **Phone widgets** on iPhone and Android, and the phone wallpaper on Android.

## An honest finish line

For a goal with an end, such as a course, Anchor shows two finish dates: one if you follow your
plan, and one at the pace you've actually kept for the last four weeks. Seeing the gap
between them is more useful than any streak.

## Nudges, not notifications

Notifications are easy to swipe away, and a Focus mode hides them. Anchor's nudges are a small
window in the middle of the screen instead.

- **Drift nudge.** Spend 15 of the last 30 minutes on drift sites and Anchor says so.
- **Calendar nudge.** During a calendar block named after a goal ("DSA, 9:00–10:00"), a nudge
  comes if 5 of the last 10 minutes went to something else. During a block like Lunch, it
  nudges you to step away from the laptop.
- **Bedtime screen.** During a Sleep block, the Mac and an Android phone dim under a "Time to
  sleep" card. There's no "stop now" button. You either put the device down or choose a snooze on a
  slider that starts at zero, and each snooze is shorter than the last. The next screen shows
  the time you agreed to stop by.

## Energy for the day

The **Energy** tab puts today's calendar beside your expected energy, hour by hour, so you can
move hard work into your best hours in the morning. It's an estimate, not a measurement. It
combines your body clock from when you woke up, your own focus by hour from past days, and how
well you slept. With an Apple Watch it can also use your resting heart rate and heart rate
variability. That part is optional and off by default.

## Private by design

- **Local first.** Everything is worked out on your Mac. Screen time comes from
  [ActivityWatch](https://activitywatch.net), which also runs on your own computer.
- **End-to-end encrypted sync.** Your phones get only a small summary, encrypted with a key
  that travels in the QR code you scan to pair them. The server that relays it can't read it.
- **Bring your own tools.** Timers, calendars and Apple Health connect to it, so you don't
  have to change how you work.

## Where it is now

I use Anchor every day on a Mac, an iPhone and an Android phone. Right now it's set up for
me: some of its settings still live in files rather than in the app. Next, I'm turning it
into something anyone can install and set up in a few minutes.

<script>
(function(){
  var API = "https://waitlist.anand-bbc.workers.dev/api/waitlist";
  var box = document.querySelector(".waitlist"), source = box.dataset.source, key = "waitlist-" + source;
  var form = box.querySelector(".wl-form"), done = box.querySelector(".wl-done"), msg = box.querySelector(".wl-msg");
  var btn = form.querySelector("button"), input = form.querySelector("#wl-email");
  function read(){ try { return JSON.parse(localStorage.getItem(key) || "null"); } catch (e) { return null; } }
  function save(v){ try { v ? localStorage.setItem(key, JSON.stringify(v)) : localStorage.removeItem(key); } catch (e) {} }
  function show(state){ form.hidden = !!state; done.hidden = !state; box.querySelector(".wl-remove").hidden = !(state && state.token); }
  function say(text, err){ msg.textContent = text; msg.classList.toggle("err", !!err); }
  show(read());

  form.addEventListener("submit", function(e){
    e.preventDefault();
    var email = input.value.trim();
    if (!/^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/.test(email)) { say("Please enter a full email address, like you@example.com.", true); input.focus(); return; }
    btn.disabled = true; say("Adding you…");
    fetch(API, { method: "POST", headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ email: email, source: source, website: form.website.value }) })
      .then(function(r){ return r.json().then(function(b){ return { ok: r.ok, b: b }; }); })
      .then(function(res){
        if (!res.ok) throw new Error(res.b.error || "Something went wrong.");
        var state = { token: res.b.token || null };
        save(state); say(""); show(state);
        if (res.b.already) done.querySelector("p").innerHTML = "<strong>You're already on the list.</strong> I'll email you when Anchor is ready.";
      })
      .catch(function(err){ say(err.message === "Failed to fetch" ? "Couldn't reach the server. Please try again." : err.message, true); })
      .then(function(){ btn.disabled = false; });
  });

  box.querySelector(".wl-remove").addEventListener("click", function(){
    var state = read(); if (!state || !state.token) return;
    var b = this; b.disabled = true;
    fetch(API + "/remove", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ token: state.token }) })
      .then(function(r){ if (!r.ok) throw new Error(); save(null); input.value = ""; show(null); say("Removed. Your email has been deleted."); })
      .catch(function(){ b.disabled = false; b.textContent = "Couldn't remove it. Try again"; });
  });
})();
</script>
